# Cyclistic Bike-Share Analysis

**Author:** Elyas Zulqarnain
**Type:** Case study (Google Data Analytics Certificate capstone)
**Tools:** Power BI, Power Query, DAX
**Data:** Divvy trip data, Q1 2019 and Q1 2020 (public data provided with the case study)

## Business task
Cyclistic, a Chicago bike-share company, wants to convert casual riders into annual members. This project compares how members and casual riders use the bikes differently, to support a marketing strategy aimed at casual riders.

## Summary of results
- About 791,746 rides remained after cleaning.
- Casual riders take longer rides on average than members.
- Members ride mostly in the morning and evening, which suggests commuting.
- Casual riders ride more on weekends.
- Popular start stations differ between the two groups.

See `05_Share` for the full report.
