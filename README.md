# Cyclistic Bike-Share Analysis (Power BI)

Portfolio project #1 — **Data Analytics**. The Google Data Analytics capstone
("Cyclistic"), done end-to-end in **Power BI**: cleaning, transforming, and joining two
quarters of trip data, then building a dashboard.

**Question:** How do annual members and casual riders use Cyclistic bikes differently?

## TL;DR findings
- **Members = 91.4%** of rides, but short trips (~13 min avg), spread across weekdays → commuters.
- **Casual = 8.6%** of rides, but much longer trips (~23 min median), mostly weekends → leisure/tourists.
- Casual ridership peaks at **lakefront/tourist stations** and grows into **spring**.

## Recommendations
1. Weekend / leisure membership offer.
2. Target lakefront tourist stations, timed for spring.
3. Show casual riders the cost savings of membership at the point of decision.
